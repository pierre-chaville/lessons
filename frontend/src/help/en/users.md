# Users

The Users section manages accounts and roles (based on permissions).

## Main actions

- View the user list
- Invite a user by email
- Create a user with password
- Change a user's role
- Delete a user

## Roles

- **Reader**: view-only access
- **Editor**: edit assigned lessons
- **Chief editor**: editorial supervision and advanced management
- **Admin**: full platform access

## Note

A chief editor cannot assign the Admin role and cannot modify Admin accounts.
