# Booklets

The Booklets section lets you compose multi-lesson documents and run batch operations.

## Booklet list

- Create a booklet (title, subtitle, description)
- Select template fields to include
- Track booklet status: Draft, Ready, Archived

## Booklet detail

- Add lessons with a selection modal
- Add chapters (free text, optional page break)
- Reorder items (arrows or drag and drop)
- Remove lessons or chapters
- Open a lesson directly from booklet items

## Exports and processing

- Export as PDF, Markdown, or Word
- Export/import composition as CSV
- Run pipeline steps in batch for included lessons

## Important rule

To switch to **Ready**, all included lessons must be in **Validated** status.
