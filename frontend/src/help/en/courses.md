# Courses

The Courses section manages the hierarchy used to organize and filter lessons.

## What you can do

- Create a course (root or child)
- Edit name, description, and parent
- Delete a course (with subtree reassignment)
- Reorder courses (up/down controls)
- Move courses with drag and drop

## Link with lessons

- Each lesson is attached to one course
- The tree is a primary filter on the Lessons page
- Per-node lesson count includes subcourses

## Bulk update (CSV)

- Export lessons CSV from the page header
- Edit the file and import it back
- Use the CSV format helper for accepted columns
