# Preferences

The Preferences section configures processing behavior and prompts.

## Core principles

- Changes are auto-saved
- Full configuration import/export is available in YAML
- Uses model presets defined in the Models section

## Configuration domains

- **Transcription**: model, language, audience segment prefix
- **Correction**: multiple prompts, model preset, max tokens
- **Writing**: multiple prompts, model preset, max tokens
- **Sources**: extraction and verification (prompts, preset, tokens)
- **Summary**: prompts, preset, max tokens
- **Short summary**: dedicated prompt, dedicated preset, max tokens
- **Alignment**: thresholds for summary/edited and edited/transcript alignment

## Prompt editors

Depending on your workflow, you can use a visual editor (WYSIWYG) or Markdown.
