# Lesson detail

The detail page centralizes editorial content, workflow tracking, and processing actions for a lesson.

## Displayed information

- Title, date, duration, and audio filename
- Full course path
- Linked themes
- Short summary (if present)
- Native audio player

## Workflow and pipeline

The right panel shows:

- Assigned editors
- Lesson status (based on your permissions)
- Status of each pipeline step
- The **Run tasks** button

A banner appears while processing is running.

## Available tabs

Tabs are shown dynamically when related data exists:

- Summary
- Edited version
- Sources
- Transcript
- Workflow audit log

## Common actions

- Edit summary, edited version, and transcript (with proper permissions)
- Export/import content (Markdown, Word, PDF depending on tab)
- Browse version history and restore older revisions
- Run remaining pipeline steps
