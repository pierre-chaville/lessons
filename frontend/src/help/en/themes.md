# Themes

Themes are cross-cutting labels used to categorize lessons. They can be nested into categories and ordered, the same way courses are.

## Available actions

- Create a theme (root or child)
- Edit name, description, and parent
- Delete a theme (child themes move up to the deleted theme's parent)
- Reorder themes with the up/down controls
- Move themes with drag and drop

## Impact

- A lesson can have multiple themes
- The count on each theme includes lessons tagged on that theme and its children
- Themes are available in Lessons page facets
- Deleting a theme removes it from linked lessons
