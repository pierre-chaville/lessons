# Preferences

La section Preferences permet de configurer les parametres de traitement et les prompts.

## Principes

- Edition auto-enregistree
- Import/export global en YAML
- Liaison avec les presets de modeles

## Domaines de configuration

- **Transcription**: modele, langue, prefixe des segments audience
- **Correction**: prompts multiples, preset modele, tokens max
- **Redaction**: prompts multiples, preset modele, tokens max
- **Sources**: extraction + verification (prompts, preset, tokens)
- **Resume**: prompts, preset, tokens
- **Resume bref**: prompt dedie, preset dedie, tokens max
- **Alignement**: seuils resume/version redigee et version redigee/transcription

## Editeurs de prompt

Selon le besoin, vous pouvez utiliser un editeur visuel (WYSIWYG) ou Markdown.
