# Traitement

La section Traitement centralise le suivi des taches pipeline lancees sur les sessions.

## Ce que vous y trouvez

- Les taches en cours et terminees
- L'etape de pipeline concernee
- Le statut d'execution
- Le contexte de session associe

## Utilite

- Suivre l'avancement global de production
- Identifier rapidement les echecs a relancer
- Verifier l'ordre et la completion des etapes
