# Detail d'une session

La page detail centralise le contenu editorial, le suivi de workflow et les actions de traitement d'une session.

## Informations affichees

- Titre, date, duree et nom de fichier audio
- Parcours complet de la session
- Themes associes
- Resume bref (si present)
- Lecteur audio natif

## Workflow et pipeline

Le panneau de droite affiche:

- Les editeurs assignes
- Le statut de session (selon vos droits)
- Le statut de chaque etape du pipeline
- Le bouton **Lancer les taches**

Un bandeau indique lorsqu'un traitement est en cours.

## Onglets disponibles

Les onglets apparaissent selon les donnees presentes:

- Resume
- Version redigee
- Sources
- Transcription
- Journal d'audit (workflow)

## Actions courantes

- Editer resume, version redigee et transcription (selon permissions)
- Exporter/importer des contenus (Markdown, Word, PDF selon onglet)
- Consulter l'historique et restaurer des versions
- Lancer les etapes restantes du pipeline
