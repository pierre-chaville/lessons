# Journal d'audit

La page Journal d'audit (Admin) permet de consulter les evenements techniques et fonctionnels.

## Contenu

- Horodatage et acteur
- Action et entite concernee
- Payload detaille au format JSON

## Filtres

- Filtre par acteur
- Filtre par prefixe d'action
- Filtre par periode (dates)

## Usage

Utilisez cette page pour analyser un incident, verifier une action sensible ou retracer l'historique d'une operation.
