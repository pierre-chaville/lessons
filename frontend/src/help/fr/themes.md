# Themes

Les themes servent a etiqueter les sessions de maniere transversale. Ils peuvent etre organises en categories imbriquees et reordonnes, comme les parcours.

## Actions disponibles

- Creer un theme (racine ou enfant)
- Modifier le nom, la description et le parent
- Supprimer un theme (les themes enfants remontent au parent du theme supprime)
- Reordonner les themes avec les fleches haut/bas
- Deplacer les themes par glisser-deposer

## Impact

- Une session peut avoir plusieurs themes
- Le compteur d'un theme inclut les sessions de ce theme et de ses enfants
- Les themes sont utilises dans les facettes de la page Sessions
- La suppression d'un theme le retire des sessions associees
