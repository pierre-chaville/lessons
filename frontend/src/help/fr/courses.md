# Parcours

La section Parcours permet de gerer l'arborescence utilisee pour classer et filtrer les sessions.

## Ce que vous pouvez faire

- Creer un parcours (racine ou enfant)
- Modifier nom, description et parent
- Supprimer un parcours (avec reassociation des sous-parcours)
- Reordonner les parcours (fleches haut/bas)
- Deplacer des parcours par glisser-deposer

## Lien avec les sessions

- Chaque session est rattachee a un seul parcours
- L'arborescence sert de filtre principal sur la page Sessions
- Le nombre de sessions par noeud inclut les sous-parcours

## Mise a jour en masse (CSV)

- Exporter les sessions CSV depuis l'entete de la page
- Modifier le fichier puis le reimporter
- Utiliser l'aide de format CSV pour les colonnes acceptees
