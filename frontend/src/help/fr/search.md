# Recherche de sessions

La page Recherche permet de retrouver rapidement des sessions selon vos criteres.

## Usage recommande

- Saisissez des termes cles pertinents
- Affinez avec les filtres disponibles
- Ouvrez une session pour acceder au detail et aux actions editoriales

## Bonnes pratiques

- Combinez plusieurs criteres pour reduire le bruit
- Ajustez vos termes de recherche si les resultats sont trop larges
- Utilisez ensuite les pages Sessions ou Detail pour poursuivre le travail
